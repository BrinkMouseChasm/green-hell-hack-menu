## 🧩 About

**Green Hell overlay** is a curated list of Green Hell open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource overlay, map markers
- **Quality-of-Life Helpers** — crafting notes, inventory organizer, HUD notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- Resource overlay — highlight nearby plants, stones, and water
- Map Markers — note camps, caves, and landmarks
- Stat Panel — read-only overview of health, stamina, and sanity
- Time Control Notes — adjust day/night pacing for study (1x to 5x)

### 🎒 Inventory & Crafting
- Inventory Organizer — sort and group carry items
- Crafting Notes — blueprint reference overlay
- Weight Display — carry limit visibility notes

### 🏕️ Base Layout
- Build Helper Notes — segment planning for shelters and frames
- Storage Tracker — label crates and drying racks
- Firepit Timer Notes — review burn states in the editor
